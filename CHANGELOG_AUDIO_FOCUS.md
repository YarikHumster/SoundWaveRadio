# Changelog - Audio Focus Fixes

## [1.9.9+] - 2025

### 🔧 Исправлено (Fixed)

#### Критические проблемы:
- **Автоматическое включение радио после других медиа-приложений**
  - Проблема: При воспроизведении YouTube, Spotify или других медиа, радио через некоторое время автоматически включалось
  - Решение: Правильная обработка `AUDIOFOCUS_LOSS` с полной остановкой сервиса

- **Постоянная работа сервиса**
  - Проблема: Сервис и уведомление работали постоянно, пока система не убивала приложение
  - Решение: Своевременное освобождение Audio Focus и остановка сервиса при неактивном воспроизведении

- **Отсутствие интеграции с системой Android**
  - Проблема: Плеер не интегрировался с системой, особенно на Samsung устройствах
  - Решение: Отключена автоматическая обработка Audio Focus в ExoPlayer, вся логика вручную

### ✨ Добавлено (Added)

#### Новые поля в PlayerService:
```kotlin
private var hasAudioFocus = false          // Текущее состояние Audio Focus
private var playbackDelayed = false        // Воспроизведение отложено
private var resumeOnFocusGain = false      // Возобновить при получении фокуса
```

#### Новые обработчики:
- `onIsPlayingChanged()` - автоматическое освобождение Audio Focus при остановке воспроизведения

#### Улучшенное логирование:
- Все изменения Audio Focus теперь логируются с тегом "PlayerService"
- Добавлены логи для отслеживания освобождения Audio Focus
- Улучшено логирование состояний воспроизведения

### 🔄 Изменено (Changed)

#### PlayerService.kt - Обработка Audio Focus:

**audioFocusRequest listener:**
- `AUDIOFOCUS_GAIN`: Восстановление громкости и возобновление воспроизведения (если нужно)
- `AUDIOFOCUS_LOSS`: Полная остановка сервиса (было: только пауза)
- `AUDIOFOCUS_LOSS_TRANSIENT`: Пауза с запоминанием для автоматического возобновления
- `AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK`: Уменьшение громкости до 20% (вместо паузы)

**requestAudioFocusAndPlay():**
- Добавлена обработка `AUDIOFOCUS_REQUEST_DELAYED`
- Улучшено логирование результатов запроса
- Правильная установка флагов состояния

**handlePauseCommand():**
- Добавлено освобождение Audio Focus при паузе
- Логирование действия

**stopServiceGracefully():**
- Добавлено освобождение Audio Focus перед остановкой
- Улучшено логирование

**releaseResources():**
- Добавлена проверка `hasAudioFocus` перед освобождением
- Предотвращение повторного освобождения

**onPlaybackStateChanged():**
- Добавлено освобождение Audio Focus в состоянии `IDLE`
- Улучшена логика остановки сервиса

**onTaskRemoved():**
- Улучшена логика: сервис останавливается только если не воспроизводится
- Добавлено подробное логирование

**playRadio():**
- Добавлен сброс флагов Audio Focus при новом воспроизведении
- Предотвращение конфликтов состояния

**setupPlayer():**
- Изменено: `setAudioAttributes(..., false)` - отключена автоматическая обработка Audio Focus
- Добавлен комментарий о ручной обработке

### 📝 Примечания для разработчиков (Developer Notes)

#### Важные изменения в логике:

1. **Audio Focus теперь обрабатывается вручную**
   - ExoPlayer больше не управляет Audio Focus автоматически
   - Все действия логируются для отладки

2. **Флаги состояния**
   - `hasAudioFocus` - ВСЕГДА проверяйте перед освобождением
   - `resumeOnFocusGain` - используется для автоматического возобновления
   - `playbackDelayed` - для отложенного воспроизведения

3. **Логирование**
   - Используйте `adb logcat -s PlayerService:I` для просмотра
   - Все критические действия логируются

4. **Тестирование**
   - Обязательно тестируйте на реальных устройствах
   - Особое внимание Samsung устройствам
   - Проверяйте утечки Audio Focus через `dumpsys audio`
